Features

やることは 3 つだけ

グリッドもプリセットもありません。毎日使う配置だけを、手を止めずに呼び出せます。

⌃⌥

キーボードから

⌃⌥ と ↩ ← → の 3 つ。どのアプリが前面でも届くグローバルショートカットです。アクセシビリティの許可があれば動きます。

4

トラックパッドから

4 本指のタップと左右スワイプ。3 本指や 5 本指、上下のスワイプ、ピンチには反応しないので、Mission Control や Launchpad と衝突しません。

◫

画面ごとに正しく

ウインドウが乗っている画面の作業領域を基準に配置します。外部ディスプレイでも、メニューバーと Dock を避けた領域いっぱいに広がります。

How it works

仕組み

入力から配置までの 4 段階です。判定と配置計算は AppKit に依存しない純粋なロジックで、ユニットテストで固めています。

入力

Carbon ホットキー、または MultitouchSupport から届く 4 本指のタッチフレームを受け取ります。

認識

「同時接触が 4 本ちょうど」「300ms 以内で動かない → タップ」「横に 12% 以上動く → スワイプ」を判定します。

対象取得

アクセシビリティ API で最前面のウインドウと、それが乗っている画面を特定します。ネイティブフルスクリーン中は何もしません。

配置

画面の visibleFrame から目標の矩形を計算し、「位置 → 大きさ → 位置」の順で書き込みます。

Setup

導入は 3 ステップ

自分の Mac でビルドする方法を推奨しています。Release の zip は Apple Silicon 専用で、ad-hoc 署名です。

  1. ビルドして起動する右のコマンドで build/Panely.app ができます。開くとメニューバーにアイコンが出ます。
  2. アクセシビリティを許可する起動直後に案内ウインドウが出ます。「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で Panely を有効にすると、ウインドウは自動で閉じます。
  3. 4 本指スワイプの衝突を避ける「システム設定 > トラックパッド > その他のジェスチャ」で「フルスクリーンアプリ間をスワイプ」を 3 本指にします。メニューから設定画面を開けます。
# クローンしてビルド
$ git clone https://github.com/bluerabbit/panely.git
$ cd panely
$ scripts/make_app.sh
$ open build/Panely.app
常用するとき
build/Panely.app を /Applications に移し、「システム設定 > 一般 > ログイン項目」に登録します。 移動後はアクセシビリティ許可を一度やり直します。
Notes

知っておくこと

private framework を使います

4 本指の検出には MultitouchSupport.framework を使います。App Sandbox は使えず App Store 配布はできません。OS の更新で動かなくなる可能性があります。

ネイティブフルスクリーンは対象外

フルスクリーン中のウインドウはアクセシビリティ API で動かせないため、何もしません。

署名について

ローカルビルドはキーチェーンの Apple Development 証明書を自動で使います。ad-hoc 署名だとリビルドのたびに許可が外れるためです。

設定 UI はありません

ショートカットとしきい値はコード内の定数です。変えたいときはソースを編集して再ビルドします。
